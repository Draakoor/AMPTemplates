# 🧰 AMP Templates

Templates for AMP (Application Management Panel) :  
🔗 [AMP Templates – Application Management Panel](https://cubecoders.com/AMP)

### 📦 Available AMP Templates:

- **H1-Mod**
- **HorizonMW** (H2M-Mod)
- **IW7-Mod**
- **MariaDB**
- **MySQL**

> 🧩 _For **HorizonMW**, you need to have **Python** installed on the host system and run:_  
> `pip install requests`  
> _This enables automatic installation and updates for the mod._

📘 A detailed usage guide for **HorizonMW** and **H1-Mod** is available in the Wiki:  
🔗 [Usage Wiki](https://github.com/Draakoor/AMPTemplates/wiki/Usage-for-HorizonMW-or-H1%E2%80%90Mod)

📁 **Pterodactyl Eggs** are available at:
